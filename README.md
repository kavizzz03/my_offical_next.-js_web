## 🎨 System Design Tokens (`UI-Design-2`)

The application enforces a strict, dark-mode architectural palette engineered for maximum readability and visual precision:

| Token | Hex / Spec | Usage / Role |
| :--- | :--- | :--- |
| **`ink`** | `#0E1015` | Core background, paneling, and card surfaces |
| **`line`** | `white/5` – `white/10` | Hairline grid borders & structural frames |
| **`text`** | `#E7E9EE` / `slate-400` | High-contrast primary copy & muted labels |
| **`signal`** | `#FF8A3D` | Primary accent — CTAs, active status, system highlights |
| **`pulse`** | `#7C9CFF` → `#C084FC` | Dual-tone gradient reserved for featured headlines |
| **`ok`** | `#33D17A` | System status indicators (Strictly functional, non-decorative) |

## 🚀 Key Features

* **Advanced Technical SEO:** Pre-configured OpenGraph metadata, Schema.org `Person` JSON-LD structured data, and micro-indexing tailored for backend and mobile architecture search queries.
* **Monitored API Identity UI:** Embedded live status seal (`200 OK`) and floating response chips simulating real-time telemetry.
* **Performance-First Engine:** Powered by Next.js App Router with zero unnecessary UI clutter or client-side runtime overhead.
* **Instant Connect Gateway:** Low-latency WhatsApp support widget with terminal-styled interaction overlays (`POST /direct_connect`).

## 🛠️ Stack Overview

* **Framework:** Next.js (App Router, TypeScript)
* **Styling:** Tailwind CSS + Lucide Icons
* **Core Tech Stack:** Node.js, Express, Kotlin, MySQL, PHP, Python, Docker
* **Typography:** Geist Sans & Geist Mono (`next/font/google`)
